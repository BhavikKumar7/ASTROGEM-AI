# AI Assisted Components

Artificial Intelligence was used as an assistive tool and not as a replacement for human development.

## Gemini AI
Gemini AI is used to:

- Analyze user problems.
- Interpret Vedic astrology data.
- Generate gemstone recommendations.
- Provide benefits, precautions, remedies, deity, mantra, lucky color, and lucky number.

## Vedic Astrology API
Used for:

- Birth chart generation.
- Planetary position calculations.
- Moon Rashi calculation.
- Nakshatra calculation.
- Lagna calculation.
- Behavioral predictions.

## Generative AI Assistance During Development
AI tools were used for:

- Code suggestions.
- Debugging assistance.
- Documentation generation.
- Refactoring ideas.
- Improving UI and architecture.

Final implementation decisions, integration, testing, and verification were performed manually.
